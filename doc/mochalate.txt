1. INTRODUCTION                                             *mochalate-introduction*

mochalate.nvim is a dark-only colorscheme fusing gruvbox's warm earthiness with
catppuccin's soft pastels in mochalate tones: burnt coral keywords, amber
numbers, sage-green strings, muted teal types.

Designed for long coding sessions: warm brown-black backgrounds, no pure
white text, and blended diagnostic backgrounds.

Requires Neovim 0.9+ with 'termguicolors'.

==============================================================================
2. SETUP                                                       *mochalate-setup*

Calling setup() is optional; the defaults apply without it. >lua

    require('mochalate').setup({})
    vim.cmd.colorscheme('mochalate')
<
Calling |mochalate.setup()| while the colorscheme is active reapplies it.

==============================================================================
3. OPTIONS                                                   *mochalate-options*

>lua
    require('mochalate').setup({
      transparent = false,
      terminal_colors = true,
      dim_inactive = false,
      styles = {
        comments = { italic = true },
        keywords = {},
        conditionals = {},
        functions = {},
        methods = {},
        variables = {},
        builtins = { italic = true },
        parameters = {},
        properties = {},
        types = {},
        strings = {},
        numbers = {},
        booleans = {},
        constants = {},
        operators = {},
        namespaces = {},
        macros = {},
        attributes = {},
        tags = {},
        headings = { bold = true },
        floats = 'solid',
      },
      palette = {},
      on_colors = function(colors) end,
      on_highlights = function(highlights, colors) end,
      highlights = {},
      plugins = {},
    })
<
Unknown option names and invalid `styles.floats` values produce a warning and
are ignored.

==============================================================================
4. TRANSPARENCY                                             *mochalate-transparency*

`transparent = true` clears the background of Normal, the sign column, line
numbers, the statusline and the tabline.

Floating windows are separate: `styles.floats` is one of >
    'solid'         always painted (default)
    'transparent'   never painted
    'auto'          follows `transparent`
<
==============================================================================
5. STYLES                                                     *mochalate-styles*

Each `styles.<token>` table is merged into the highlight specs for that token.
Add an attribute with `true`, remove a theme default with `false`. >lua

    require('mochalate').setup({
      styles = {
        comments = { italic = false },
        keywords = { italic = true },
        functions = { bold = true },
      },
    })
<
Valid attributes: `bold`, `italic`, `underline`, `undercurl`, `strikethrough`.

==============================================================================
6. PALETTE                                                   *mochalate-palette*

Static overrides: >lua

    require('mochalate').setup({ palette = { bg = '#151210' } })
<
Programmatic overrides, applied after `palette`: >lua

    require('mochalate').setup({
      on_colors = function(colors)
        colors.bg_float = colors.bg
      end,
    })
<
Derived keys visible to `on_colors`: `bg_normal`, `bg_panel`, `bg_float`,
`bg_inactive`, `err_bg`, `warn_bg`, `info_bg`, `hint_bg` and `terminal`.
All keys are defined in `lua/mochalate/palette.lua`.

==============================================================================
7. HIGHLIGHTS                                             *mochalate-highlights*

>lua
    require('mochalate').setup({
      on_highlights = function(highlights, colors)
        highlights.LineNr = { fg = colors.fg_dim }
      end,
      highlights = {
        Comment = { fg = '#907860' },
        Visual = { link = 'CursorLine' },
      },
    })
<
`on_highlights` runs first, then `highlights` is merged on top. Groups merge
per key; a spec containing `link` replaces the group entirely.

==============================================================================
8. PLUGINS                                                   *mochalate-plugins*

Plugin groups are enabled by default and can be disabled by key: >lua

    require('mochalate').setup({ plugins = { telescope = false } })
<
Keys: gitsigns, telescope, fzf_lua, snacks, blink, cmp, bufferline, which_key,
notify, noice, neo_tree, nvim_tree, oil, indent_blankline, mini, lazy, mason,
trouble, flash, illuminate, treesitter_context, rainbow, dap, navic, markdown,
dashboard, yanky, fidget.

lualine users can set `options.theme = 'mochalate'`.

==============================================================================
9. API                                                           *mochalate-api*

mochalate.setup({opts})                                       *mochalate.setup()*
    Stores {opts}. Reapplies the colorscheme if it is already active.

mochalate.load({opts})                                         *mochalate.load()*
    Applies the colorscheme. {opts} override the stored config for this call.

mochalate.colors({opts})                                     *mochalate.colors()*
    Returns the resolved palette table.

mochalate.highlights({opts})                             *mochalate.highlights()*
    Returns the resolved highlight table and palette without applying them.
